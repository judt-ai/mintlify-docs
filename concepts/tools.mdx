JUDT Tools are ready-made capabilities that your app or agent can invoke without you having to build or maintain the underlying infrastructure. Browse the catalog, enable what you need, and start calling tools immediately — JUDT handles everything else.

## What Is a Tool?

A Tool is a discrete capability — such as web search, file reading, code execution, or data lookup — that JUDT hosts and exposes via API. You decide which tools your app uses; your agent (or your own code) calls them at runtime. There is no server to provision, no third-party SDK to wire up, and no rate-limit plumbing to manage. JUDT takes care of the underlying service so you can focus on your product.

## Tool Lifecycle

<Steps>
  <Step title="Browse available tools">
    Open the JUDT dashboard and navigate to the **Tools** catalog to see every tool available for your app.
  </Step>
  <Step title="Enable and configure a tool">
    Select the tools your app needs, toggle them on, and set any tool-specific configuration options (see [Tool Configuration](#tool-configuration) below).
  </Step>
  <Step title="Call the tool via the API">
    Invoke enabled tools from your app or agent using the JUDT REST API. Your agent can also select and call tools autonomously at runtime.
  </Step>
  <Step title="Monitor usage in the dashboard">
    Track invocation counts, latency, and errors for every tool under your app's **Usage** tab.
  </Step>
</Steps>

## Tool Configuration

Each tool exposes a set of configurable parameters that let you tailor its behavior for your app. You set these parameters when you enable the tool in the dashboard or via the API, and you can update them at any time.

```json
{
  "app_id": "app_xyz789",
  "tool_id": "web-search",
  "enabled": true,
  "config": {
    "max_results": 10,
    "safe_search": true
  }
}
```

Configuration is stored per app, so different apps (for example, a dev environment vs. a production environment) can use the same tool with different settings.

## Tool Invocation

Once a tool is enabled for your app, call it at runtime by sending a request to the JUDT invoke endpoint. Pass the `tool_id` along with any input parameters the tool requires. JUDT executes the tool and returns a structured response your app can act on immediately.

See the [Invoke API reference](/api-reference/tools/invoke) for the full request and response schema, authentication requirements, and error codes.
