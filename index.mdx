## Get Started in Three Steps

<Steps>
  <Step title="Create Your Account & Get an API Key">
    Sign up at [app.judt.com](https://app.judt.com) and navigate to **Settings → API Keys** to generate your first API key. Store it securely — you'll need it for every request.
  </Step>
  <Step title="Configure the Tools Your App Needs">
    Browse the JUDT tool catalog and enable the tools that match your use case — web search, code execution, data retrieval, and more. No servers to spin up, no dependencies to manage.
  </Step>
  <Step title="Call the JUDT API from Your App or Agent">
    Invoke any configured tool with a single API call. Your app or AI agent gets the result back in structured JSON, ready to use immediately.
  </Step>
</Steps>

<Note>
  Ready to build? Head to the [Quickstart](/quickstart) to create your account, configure your first tool, and make your first API call in under 10 minutes.
</Note>
