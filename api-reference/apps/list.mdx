Use this endpoint to retrieve all apps in your JUDT account. The response includes each app's environment, the number of tools currently enabled, and the number of agents associated with it. Results are paginated — use the `page` and `limit` query parameters to navigate large sets.

**Endpoint:** `GET https://api.judt.com/v1/apps`

**Required scope:** `read`

---

## Query Parameters

<ParamField query="environment" type="string">
  Filter results to apps in a specific environment. Accepted values: `development`, `staging`, `production`. Omit this parameter to return apps across all environments.
</ParamField>

<ParamField query="page" type="integer" default={1}>
  The page number to return, starting from `1`. Use in combination with `limit` to paginate through your full list of apps.
</ParamField>

<ParamField query="limit" type="integer" default={20}>
  The number of apps to return per page. Minimum `1`, maximum `100`.
</ParamField>

---

## Request Example

<CodeGroup>

```bash cURL
curl --request GET \
  --url 'https://api.judt.com/v1/apps?environment=production&page=1&limit=20' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```python Python
import requests

response = requests.get(
    "https://api.judt.com/v1/apps",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    params={"environment": "production", "page": 1, "limit": 20},
)

result = response.json()
apps = result["data"]
meta = result["meta"]
print(f"Page {meta['page']} of {meta['total']} total apps")
```

</CodeGroup>

## Response

A successful request returns HTTP `200 OK` with an array of app objects and pagination metadata.

```json
{
  "success": true,
  "data": [
    {
      "id": "app_xyz789",
      "name": "My Product",
      "environment": "production",
      "tools_enabled": 3,
      "agent_count": 2,
      "created_at": "2024-01-10T08:00:00Z"
    }
  ],
  "meta": { "total": 1, "page": 1, "limit": 20 }
}
```

<ResponseField name="id" type="string">
  The unique identifier for the app, prefixed with `app_`. Use this value as `app_id` when creating agents or configuring tools.
</ResponseField>

<ResponseField name="name" type="string">
  The display name of the app as set at creation time.
</ResponseField>

<ResponseField name="environment" type="string">
  The environment this app is associated with — one of `development`, `staging`, or `production`.
</ResponseField>

<ResponseField name="tools_enabled" type="integer">
  The number of tools currently enabled and available for agents in this app.
</ResponseField>

<ResponseField name="agent_count" type="integer">
  The total number of agents that have been created within this app.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp recording when the app was created, in UTC.
</ResponseField>

<ResponseField name="meta.total" type="integer">
  The total number of apps matching your query across all pages.
</ResponseField>

<ResponseField name="meta.page" type="integer">
  The current page number returned in this response.
</ResponseField>

<ResponseField name="meta.limit" type="integer">
  The number of results per page used for this response.
</ResponseField>
