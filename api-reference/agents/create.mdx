---
title: 'Create a New JUDT Agent with Tools and System Prompt'

description: 'Create a new agent inside an existing JUDT app. Set its tool list, system prompt, and timeout — the response includes the agent ID for all future calls.'
---

Use this endpoint to create a new agent within one of your JUDT apps. You define which tools the agent can access, how it should behave via a system prompt, and optional runtime constraints like a timeout. The response includes the agent's `id`, which you'll use for all subsequent operations on that agent.

**Endpoint:** `POST https://api.judt.com/v1/agents`

**Required scope:** `write`

---

## Request Body

<ParamField body="app_id" type="string" required>
  The ID of the app this agent belongs to. All agents must be scoped to an app. You can find your app IDs via [GET /v1/apps](/api-reference/apps/list).
</ParamField>

<ParamField body="name" type="string" required>
  A human-readable display name for the agent — for example, `"Research Assistant"` or `"Support Bot"`. This name appears in the JUDT dashboard and in API responses.
</ParamField>

<ParamField body="tools" type="string[]" required>
  An array of `tool_id` values representing the tools this agent is allowed to invoke. The tools must already be enabled on the parent app. Pass an empty array `[]` to create an agent with no tools.
</ParamField>

<ParamField body="system_prompt" type="string">
  Instructions that define how the agent should behave — its persona, constraints, response style, and task focus. If omitted, the agent uses JUDT's default system prompt.
</ParamField>

<ParamField body="timeout_ms" type="integer" default={60000}>
  Maximum wall-clock time, in milliseconds, that a single agent run is allowed to execute before it is terminated. Defaults to `60000` (60 seconds). The maximum allowed value is `300000` (5 minutes).
</ParamField>

<ParamField body="metadata" type="object">
  An arbitrary set of key-value pairs you can attach to this agent for your own tracking, filtering, or display purposes. Keys and values must be strings. JUDT does not interpret this data.
</ParamField>

## Request Example

<CodeGroup>

```bash cURL
curl --request POST \
  --url https://api.judt.com/v1/agents \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "app_id": "app_xyz789",
    "name": "Research Assistant",
    "tools": ["web-search", "data-lookup"],
    "system_prompt": "You are a research assistant. Always cite sources and summarize findings concisely.",
    "timeout_ms": 60000,
    "metadata": {
      "team": "growth",
      "version": "1"
    }
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.judt.com/v1/agents",
    headers={
        "Authorization": "Bearer YOUR_API_KEY",
        "Content-Type": "application/json",
    },
    json={
        "app_id": "app_xyz789",
        "name": "Research Assistant",
        "tools": ["web-search", "data-lookup"],
        "system_prompt": "You are a research assistant. Always cite sources and summarize findings concisely.",
        "timeout_ms": 60000,
        "metadata": {
            "team": "growth",
            "version": "1",
        },
    },
)

agent = response.json()["data"]
print(agent["id"])  # agent_abc123
```

</CodeGroup>

## Response

A successful request returns HTTP `201 Created` with the full agent object.

```json
{
  "success": true,
  "data": {
    "id": "agent_abc123",
    "app_id": "app_xyz789",
    "name": "Research Assistant",
    "tools": ["web-search", "data-lookup"],
    "system_prompt": "You are a research assistant...",
    "timeout_ms": 60000,
    "metadata": {},
    "created_at": "2024-01-15T10:00:00Z"
  }
}
```

<ResponseField name="id" type="string">
  The unique identifier for the newly created agent. Use this value in path parameters for [GET /agents/:id](/api-reference/agents/get), [PATCH /agents/:id](/api-reference/agents/update), and all run-related endpoints.
</ResponseField>

<ResponseField name="app_id" type="string">
  The ID of the app this agent is scoped to.
</ResponseField>

<ResponseField name="name" type="string">
  The display name you provided for the agent.
</ResponseField>

<ResponseField name="tools" type="string[]">
  The array of `tool_id` values assigned to this agent at creation time.
</ResponseField>

<ResponseField name="system_prompt" type="string">
  The instruction set governing the agent's behavior. Returns `null` if no system prompt was supplied.
</ResponseField>

<ResponseField name="timeout_ms" type="integer">
  The maximum runtime in milliseconds allowed for a single agent run.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp recording when the agent was created, in UTC.
</ResponseField>

<Tip>
  Store the returned `id` (for example, `agent_abc123`) — you'll pass it as the path parameter in all subsequent `/agents/{id}` calls, including retrieving details, updating configuration, and triggering runs.
</Tip>
