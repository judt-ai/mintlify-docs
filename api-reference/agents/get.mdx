title: 'Retrieve Full Configuration Details for a JUDT Agent'

---

Use this endpoint to fetch the full configuration of a specific agent — including its tool list, system prompt, timeout, and metadata. The agent must belong to an app in your account; you cannot retrieve agents from other accounts even if you know their ID.

**Endpoint:** `GET https://api.judt.com/v1/agents/{agent_id}`

**Required scope:** `read`

---

## Path Parameters

<ParamField path="agent_id" type="string" required>
  The unique identifier of the agent you want to retrieve. Agent IDs are returned when you [create an agent](/api-reference/agents/create) and are prefixed with `agent_`.
</ParamField>

---

## Request Example

<CodeGroup>

```bash cURL
curl --request GET \
  --url https://api.judt.com/v1/agents/agent_abc123 \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```python Python
import requests

response = requests.get(
    "https://api.judt.com/v1/agents/agent_abc123",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
)

agent = response.json()["data"]
print(agent["name"])  # Research Assistant
```

</CodeGroup>

---

## Response

A successful request returns HTTP `200 OK` with the full agent object.

```json
{
  "success": true,
  "data": {
    "id": "agent_abc123",
    "app_id": "app_xyz789",
    "name": "Research Assistant",
    "tools": ["web-search", "data-lookup"],
    "system_prompt": "You are a research assistant. Always cite sources and summarize findings concisely.",
    "timeout_ms": 60000,
    "metadata": {
      "team": "growth",
      "version": "1"
    },
    "created_at": "2024-01-15T10:00:00Z"
  }
}
```

<ResponseField name="id" type="string">
  The unique identifier for this agent, prefixed with `agent_`.
</ResponseField>

<ResponseField name="app_id" type="string">
  The ID of the app this agent belongs to.
</ResponseField>

<ResponseField name="name" type="string">
  The human-readable display name of the agent.
</ResponseField>

<ResponseField name="tools" type="string[]">
  The list of `tool_id` values this agent is currently authorized to use.
</ResponseField>

<ResponseField name="system_prompt" type="string">
  The instruction set that governs the agent's behavior. Returns `null` if no system prompt was set at creation.
</ResponseField>

<ResponseField name="timeout_ms" type="integer">
  The maximum runtime, in milliseconds, allowed for a single agent run.
</ResponseField>

<ResponseField name="metadata" type="object">
  The arbitrary key-value pairs attached to this agent. Returns an empty object `{}` if no metadata was provided.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp recording when the agent was created, in UTC.
</ResponseField>

---

## Not Found

If `agent_id` does not exist, has been deleted, or belongs to an app outside your account, the API returns HTTP `404 Not Found`:

```json
{
  "success": false,
  "error": {
    "code": "AGENT_NOT_FOUND",
    "message": "No agent found with ID agent_abc123. Verify the ID and ensure it belongs to an app in your account."
  }
}
```

Check that you are using the correct `agent_id` from your [Create Agent](/api-reference/agents/create) response and that you are authenticating with an API key that has access to the app the agent belongs to.
